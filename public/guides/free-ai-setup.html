What the AI does, and why you bring a key

ApplyStack itself is free. Its AI features run on an AI provider of your choice, using your own API key (a password-like code that lets the app use your account with that provider). You need a key for:

  • Resumes tailored to each job, from your Profile, and the fact check that catches anything your profile doesn't back up
  • Answers for application forms, cover letters and "Why this company?"
  • Filling in application forms from the browser extension

Everything else, like the board, saving jobs, the resume keyword score and the visa-sponsorship check, works without a key.

Why a backup? Free plans get the lowest priority, so at busy times a provider sometimes answers "overloaded". ApplyStack retries for a few seconds and, if you've added a backup, switches to it instead of failing. It never keeps retrying for long: within about a minute you get an answer or a clear error.

Step 1: Get a free Gemini key

  1. Open Google AI Studio → API keys and sign in with your Google account.
  2. Tap Create API key. If it asks for a project, let it create one.
  3. Copy the key. It's a long code that starts with AIza.

Treat the key like a password: don't post it or share it.

Step 2: Connect it to ApplyStack

  1. In ApplyStack, open the Profile tab and find the AI provider box.
  2. Set Provider to Google Gemini.
  3. Paste the key into API key. The model list fills in by itself.
  4. Pick a Model with flash in its name. Flash-Lite models are often less busy, and they're plenty for resumes and form answers.
  5. Tap Save, then Test. You should see "Connected ✓".

While you're on the Profile tab, paste your full resume into Your profile. The AI only uses facts from there, so the more complete it is, the better your tailored resumes.

Step 3: Add Groq as a backup

Groq has a free plan that's very fast, which makes it a good fallback for when Gemini is busy.

  1. Open console.groq.com/keys and sign up (Google sign-in works).
  2. Tap Create API Key, give it any name, and copy it. It starts with gsk_.
  3. Back in ApplyStack's AI provider box, set Provider to Groq and paste the key.
  4. Pick the largest general model in the list. Model names usually include their size, like 120b or 70b; skip ones for speech, vision or safety.
  5. Tap Save as backup, not Save. Gemini stays your main provider, and the box shows Backup when it's busy: Groq.
  6. Tap Test. It checks both and should say the backup works too.
Tip: when the backup answers, ApplyStack tells you ("Your main AI provider was busy, so Groq answered"). You can change or remove the backup any time in the same box.

If something goes wrong

"The provider is overloaded right now"

The provider's servers are busy; it's not your key. ApplyStack already retried a few times. Add a backup (Step 3), or try again in a few minutes.

"Rate limited or out of free quota"

You've used up the free requests for now. Per-minute limits clear within a minute; daily limits reset the next day. A backup keeps you going meanwhile.

"The provider rejected the API key"

The key was copied incompletely, deleted, or belongs to a different provider than the one selected. Copy it again (no spaces before or after) and make sure the Provider matches.

"Choose a model" or an empty model list

The model list only loads once the key works. Re-paste the key, then pick a model. You can also type a model name from the provider's website.

Both main and backup failed

The message shows what each one said. Usually both free plans hit their limits at once; wait a little, or add a third provider as the backup instead.

Privacy

  • Your key is stored in this ApplyStack's database and is never sent back to your browser. The person who runs this ApplyStack can technically see it (see the privacy policy).
  • When you use an AI feature, the text it needs, like the job description and your profile, goes to the provider you picked.
  • On free plans, some providers may use what you send to improve their products. Check their terms; if that matters to you, use a paid plan.
